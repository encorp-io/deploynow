Everything in one place

    
Two tools became one.
Then we kept going.

    
Container management, app deploys, edge routing, secrets, backups and monitoring share one data model, one permission system and one audit log.


    

      

        

        
Every machine, one dashboard

        
The local Docker socket, machines over SSH or TLS, and machines behind NAT through a tiny outbound agent. Mutual TLS, no open ports.

        

          
        

      


      

        

        
Deploy anything

        
An image from GHCR or Docker Hub, a Dockerfile or compose file in Git, or a pasted compose file. Zero-downtime replace and one-click rollback.

      


      

        

        
Push to deploy, with previews

        
GitHub webhooks deploy on push. Every pull request gets its own preview at pr-<n>.your.domain.

      


      

        

        
Domains and SSL, handled

        
Managed Traefik with Let's Encrypt over HTTP or Cloudflare DNS. Redirects and password protection per domain.

      


      

        

        
Secrets that stay secret

        
Encrypted at rest, masked in the UI and in logs. Point to HashiCorp Vault paths when production needs it.

        

          DATABASE_URL••••••••••••••vault
        

      


      

        

        
See everything, get told early

        
Live logs, stats and an in-browser console for every container. Usage history per app, Prometheus metrics with a ready Grafana dashboard, and alerts for disk, memory, crash loops and failed jobs to Slack, Discord, Telegram, email or a signed webhook.

        

          
        

      


      

        

        
CLI and API first

        
API tokens, an OpenAPI description and the deploynow CLI for CI pipelines and scripts.

      

    

  







  

    
How it works

    
From a bare server to production
in three steps.

    
    
      
  1. 
        01
        
    Run one container
    
        
    Start DeployNow with Docker Compose. It brings its own database and manages the machine it runs on right away.
    
        
    $ docker compose up -d
    
      
    2. 
      
  2. 
        02
        
    Connect your machines
    
        
    Add machines over SSH or TLS, or paste one docker run line to join a machine behind NAT through the agent.
    
        
    $ docker run … deploynow-agent
    
      
    3. 
      
  3. 
        03
        
    Ship your apps
    
        
    Create a project, pick a source, add a domain and secrets, and deploy. Every rollout is logged and can be rolled back.
    
        
    $ deploynow deploy shop/production/web
    
      
    4.

Security and access

    
Root on every machine
deserves serious locks.

    

      
Passkeys and 2FA
TOTP and WebAuthn passkeys. Admins must have one.

      
Single sign-on
Google, Microsoft or any OpenID Connect provider.

      
Fine-grained roles
Viewer, operator, admin and owner, granted per machine and per project.

      
Step-up for danger
A fresh 2FA code before destructive actions. Sessions you can revoke.

      
Full audit log
Who did what, where and when, for every change.

      
mTLS agents
Agents dial out over mutual TLS. Nothing listens on the remote machine.

    

  







  

    

      
Quick start

      
Running in
five minutes.

      
You need a Linux machine with Docker. Then open https://your-server:9444, sign in, and set up a passkey.

      

        
9444Dashboard

        
8444Agents (optional)

      

    

    

      

        
        bash
        
      


# 1. Get DeployNow
git clone https://github.com/encorp-io/deploynow.git
cd deploynow

# 2. Configure
cat > .env <<EOF
AUTH_SECRET=$(openssl rand -base64 32)
ADMIN_EMAIL=you@example.com
ADMIN_PASSWORD=choose-a-long-password
NEXTAUTH_URL=https://your-server:9444
DOCKER_GID=$(stat -c %g /var/run/docker.sock)
EOF

# 3. Start
docker compose up -d
